# 有界运行时图片缩放

`verify.py --tool-dir <Icarus bin>`使用当前生产RTL，参考源冻结在本阶段before目录。

- 启用后接受目标尺寸或宽高均减半的RGB24未压缩BMP；主板配置为640×480原尺寸、320×240二倍最近邻放大。两种尺寸运行时按文件头识别，不需要重综合。
- 独立按目标坐标计算源像素颜色，检查每个地址恰好写一次、全帧覆盖、RGB顺序和上下方向。小参数覆盖1/2/3字节行填充，640×480参数检查四完整输出帧。
- 随机字节空隙/输出背压、最后输出块停顿、非法宽高组合/高位、格式/偏移/长度、早EOF、4个复制位置的传输取消、异步复位及不复位连续切换。
- 启用缩放时，原尺寸输入的全部61位公开输出与P1冻结解码器逐周期比较，包括无效周期。
- 真正640×480 `fat32_frame_loader`加P1预读控制及SD仲裁：320正高度与640负高度混播。受检RAM接收端提供背压/排空；文件后段CRC状态连续三次失败时，部分缩放帧不提交，旧图保留，随后可恢复。音频扇区归属逐字节检查。

此集成测试使用受检RAM接收模型；实际SDRAM控制器与25MHz光栅由完整回归另行覆盖。这里不宣称任意尺寸、双线性、压缩BMP或宽高比变化已支持。
