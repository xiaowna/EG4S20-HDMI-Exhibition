# 统一控制入口 T01

`python -B tests/control_events/verify.py --tool-dir "Icarus bin目录"`

- 对enable及三个来源的全部4位事件组合穷举8192种输入，以手写16项真值表检查优先级、左右取消和one-hot/零输出。
- reference中冻结修改前O12的控制器，仅更改模块名，原始及副本哈希记录在source.json。通过真实按键序列到达500种状态／设置组合，各测试全部16种按键掩码，共8000个试验，逐拍对比全部27位公开输出。
- 再检查每个来源及20000拍混合来源操作、复位、连续事件；同一拍的低优先级事件明确丢弃，不排队补发。
- 真实矩阵扫描、20ms去抖、鬼键互锁和板级接线由tests/dmz_media覆盖；本步骤不添加滚轮／红外物理引脚，也不改原控制器状态机。

来源必须先转换为sys_clk域的一拍脉冲。当前顶层只启用物理按键，另外两路固定0；因此验证未来入口规则不等于外设驱动已实现。
