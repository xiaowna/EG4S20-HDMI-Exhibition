# 几何三维太阳系独立验收

运行：

```powershell
python -B tests/solar_scene/verify.py --tool-dir C:/iverilog/bin
```

本目录验证当前 `video_scene3d.v` 和 `media_3d_control.v`。太阳与八颗行星均使用三维 XYZ 球体，每个模型50个顶点、64条经纬线边：45°、0°、−45°三条16段纬圈，四条半经线连接两极。经过相机旋转、正交投影和Bresenham画线生成，保留透明线框风格。天体进一步放大，海王星轨道半径调整为57以保留完整边界。旧 `tests/scene3d` 的立方体黄金结果不适用于本版本。

已核对：

- 49 组完整画布：8 档速度 × 2 视角、8 组共线/遮挡、8 组相机极限、16 组掠射/微小线段姿态，以及从全部相机姿态中找出的最坏绘制姿态，共 802816 个画布像素。
- Python独立从球面公式计算XYZ、相机旋转、64条边、整数线段像素、物体深度顺序与土星前后环。黄金结果不读取DUT中间状态。
- 由16个闭合面独立推导64条唯一边，并核对50顶点、64边、16面的Euler关系，每条边恰有两个邻面；渲染器只使用边。
- 数学参考枚举15×128=1920个相机姿态和各天体128个轨道相位的边界极值，检查完整球体不越框。覆盖全部8个画线象限，以及水平、垂直、对角线、重复端点和严格比较平局规则。数学枚举不等同于1920组RTL仿真。
- 九模型的最坏线样本姿态由数学参考自动选择，加入RTL逐像素比较，具体样本数和姿态见summary.json。
- 640×480完整扫描，共307200个RGB像素，包含背景星点、边框、3倍画布放大、1倍中文标签和透明禁用。
- 行为相位 RAM 和实际 FPGA 条件编译分支各执行一遍完整画布与扫描验证；后者连接公开的 EG4 BRAM32K 双端口配置契约模型，不代表厂商加密时序仿真。
- 八颗行星在全部速度下相位增量均为正，切速不重置相位；未显示时停止相位推进。额外 16 帧烟雾仿真覆盖全部速度与两种预设视角。
- 过早进入有效视频或超过45000拍守卫时拒绝发布不完整画布；帧间冷初始化不依赖相位RAM的上电数据。
- 全部49组场景核对随投影移动的标签锚点。名字使用既有侧栏ROM读口；太阳、月球字形放在原空白边缘，侧栏输出屏蔽这两块字形区域。地月57组场景与完整栅格另由tests/earth_moon验证。默认视角九个名字框互不重叠；极端视角允许交叠并采用稳定优先级，不增加避让处理器。
- KEY1/3 调速、KEY2 切换预设视角；KEY9/11 左右环绕、KEY14/6 上下旋转、长按重复、KEY10 归位；验证速度上下限、角度环绕及设置页暂停控制。
- 固定 1kHz 测试音的 48 个采样、立体声、背压等待和复位，在 480kHz/50MHz 两种时钟参数下均经过检查。

最坏一帧实测渲染44443个50MHz时钟，约0.88886ms；小于45000拍守卫及板级56000拍消隐预算。顶点变换共用一个有符号8×8乘法路径；画线逐像素仅做比较与加减。画布为128×128×3bit，顶点使用原相位RAM空余槽。完整画布发布后，在10个消隐像素时钟内串行计算名字锚点，复用一套上下限处理器与140位锚点缓存；此时距离下一帧还有超过11000个系统时钟，投影中心保持不变，bench检查串行加载不进入有效视频或投影中心改写状态。用原canvas_x/y和两位子像素余数绘制清晰12px中文，不增加RAM或DSP，也不改变像素valid延迟。实际资源和时序以整机TD报告为准，实板效果待用户验收。

定点约定：顶点的每个Q7乘积先按 `(product+64)>>7` 舍入，半值向正无穷；缩放按 `(coordinate*radius+16)>>5` 舍入为整数像素。中心、轨道和土星环按逐乘积向下取整。线段包括两个端点；每步用旧误差的两倍，当 `e2>-abs(dy)` 移动X，当 `e2<abs(dx)` 移动Y。土星环在XZ平面生成半径14的圆周，再按相机俯仰连续投影，按远半圈、模型、近半圈绘制。

透明线框允许后方棱线穿过正面轮廓，模型间按物体中心深度排序；本版没有逐像素深度缓冲、隐藏线消除或抗锯齿，也没有透视近大远小。三维模型与相机运算仍是真正的 XYZ 几何，正交投影与旧立方体一致。

显示约定：太阳与八大行星、八条示意轨道；行星半径、轨道间距与起始位置为展陈示意，并非真实比例，也不计算当日星历。公转相位的相对速度近似按恒星公转周期设定；默认 1 倍时一个模拟日约 0.1 秒，地球约 36.5 秒一圈，海王星约 100 分钟一圈。因此默认下外行星看起来移动很慢是预期行为。

数据核对：

- [NASA/GSFC 水星事实表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/mercuryfact.html)：恒星公转周期约 87.969 天。
- [NASA/GSFC 海王星事实表](https://nssdc.gsfc.nasa.gov/planetary/factsheet/neptunefact.html)：约 60189.018 天，约 164.79 个地球年。
- [NASA/JPL 行星物理参数](https://ssd.jpl.nasa.gov/planets/phys_par.html)：恒星公转周期的定义与行星参数。

为控制资源，本版将文档中的“长按确定两秒复位”改为现有 KEY10 一键归位，未添加调速提示音、运动残影、球面纹理、椭圆轨道或真实倾角。归位重置速度与视角，行星相位保持连续。
