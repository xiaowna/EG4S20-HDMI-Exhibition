# WAV 单字节弹性边界定向验证

```powershell
python -B tests/wav_elastic/verify.py --tool-dir C:/iverilog/bin
```

测试使用真实 `fat32_wav_player`、`fat32_file_reader` 和 `wav_pcm_decoder`，模拟完整 512 字节扇区及滞后的 CRC/完成边界。独立生成 48kHz 立体声 PCM 文件与期望样本，16 位和 24 位各验证以下六种情况：

- 文件最后一个字节已进入弹性缓冲，但解码器暂停：完成脉冲被保存，最后字节不会被提前当作截断。
- 旧文件最后一个样本暂停时，下一文件首字节 `R` 保留，reader 的下一字节 `I` 保持阻塞；恢复后循环样本不丢失、不重复。
- 下一文件仅一个字节或为空：其 EOF 可在 DRAIN 中发生，先退役旧样本，再拒绝无效文件；受控重播可恢复。
- 下一文件 RIFF 长度超出真实文件长度：旧样本保持完整，随后准确拒绝截断文件，不产生额外样本。
- SD 扇区传输中途停止：不提前宣告 idle，不发重叠请求，等完整事务结束后重播另一组 PCM。
- 下一 `R` 已预取、旧样本尚未发送时停止：显式停止丢弃旧会话状态，重播不会泄漏旧样本或旧头字节。

共 12 个定向用例通过。输入源码 SHA256 记录于 `summary.json`，测试结束验证源码未变化。这些是 RTL 软仿真，不代替实际 TF 卡、SD 电气或 HDMI 音频验收。
