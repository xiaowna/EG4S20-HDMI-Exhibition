# T02：SW7双模式及安全音源切换

统一入口：`python -B tests/mode_switch/verify.py --tool-dir "Icarus bin目录"`。

全部12组仿真必须通过；`--only`仅用于开发定位，不替代完整验收。

- SW7消抖：COUNT=1/2/7/32/1000000；两个上电档位、短抖动、等待WAV、连续拨动合并、途中复位。
- 音频清空：17种异步时钟相位，真实双时钟FIFO，包边界前不清空、双域复位／释放、写读样本来源及次序。
- 设置：产品默认手动，第五页AUTO开／关；演示模式强制自动；切模式只清菜单／暂停／自动开关，保留图像参数。
- WAV：11个文件／扇区／FAT／预读状态停止，整扇区完成后退出，重新进入从样本0开始。检查曾停留的解析器样本不在重启时泄漏。
- 实际sd_media_player＋仲裁器：逻辑文件先超时而卡仍在传输时，不提前报告wav_idle；512字节全部完成后才允许恢复。
- HDMI：真实800×525扫描、50MHz系统时钟、48kHz测试音和1024样本预充，两个音源都进入HDMI；READ/CAPTURE/READY/SEND时切换，无旧音源进入切换后的编码包。
- OSD：45056个独立参考像素，DEMO／SHOP／WAIT与AUTO文字、开关条及高亮；帧中输入改变只能在下一帧显示。
- 图片：真实帧缓存与存储写入记分板，手动时预读但不自动提交，AUTO开／关、暂停、反向缓存未命中和坏图保护。

目录与物理SPI模型在专项中按范围隔离，完整目录、SD时序及错误恢复仍由总回归覆盖。软件模型不能代替实板的电平、TF卡、HDMI显示器与听音验收。
