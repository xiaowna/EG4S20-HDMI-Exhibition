# OSD对齐译码等价测试

运行 `python tests/osd_lookup/verify.py --tool-dir "Icarus bin目录"`。
只读参考为`reports/osd_lookup_20261018/before/worktree/rtl/video_scroll_osd.v`。

临时生成参考实例，逐次比较RGB和公开X/Y坐标，共44位，在上升/下降沿后检查。
三组测试、四个实例共9999624次比较：原字幕/状态栏独立字形参考、12帧菜单独立像素参考，以及坐标1024回绕、任意DE/VSYNC/RGB/元数据和异步复位。
旧字幕测试会直接设置DUT的坐标寄存器，临时副本把同一刺激镜像到参考实例，原来的独立字形断言保持不变。
候选中若含font_pixel函数，还会对全部2048个字库像素与冻结行字库作逐位比较；当前最终候选保留原字库，主要优化坐标/档位译码。

测试在临时目录运行，不向TD登记测试模块；任何参考输出不一致都会使测试失败。源码摘要在运行前后核对。
