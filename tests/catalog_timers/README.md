# 挂载与目录外层计时器定宽

基线冻结在`reports/catalog_timers_20261019/before/worktree/rtl`，比较全部公开输出，保留现有超时周期与错误语义。

- 复用BPB独立算术/传输参考，两种超时参数覆盖完整扇区、边界、坏格式、乱序与复位。
- 15种BPB计时参数，包括1、2、二次幂前后和实际50000000周期配置，检查准确终止拍、数据/start竞争、异步复位、重复启动和空闲字节。
- 四种目录配置：1/4张BMP及首个WAV；启动/根目录CRC错误、短扇区、未就绪/无响应超时、乱序、busy时start、目录阶段计数边界、目录接收中复位及不复位恢复。单独断言根目录无响应分支确实执行。
- 大超时仅通过给新旧实例写入相同的计数值跳过等待时钟，不声称实际运行了5000万等待周期；小参数按真实周期自然执行，目录阶段计数回卷或保持也有独立边界覆盖。判据为公开输出与独立成功/错误/超时断言，不把内部计数器相等作为通过条件。

仅适用于TIMEOUT_CYCLES≥1。CRC、格式、长度、FAT与安全提交逻辑不变。
