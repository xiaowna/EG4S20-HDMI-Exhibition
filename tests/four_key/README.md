# 四键、共享去抖与运行时设置面板

运行 `python tests/four_key/verify.py --tool-dir "Icarus bin目录"`。

- 导航：76次加载，1～4张，双向循环、暂停中手动操作、加载期间合并最后方向、背压、随后自动正向播放。
- 共享去抖：COUNT=1/2/3/7/8/9/32/1000000，检查精确边界、短抖动、候选按键变化时重新计时和单次按住。
- OSD：独立ASCII字形和几何参考，12帧921600个面板像素；覆盖高亮页、各档位、开关、帧中变更和关闭面板。输出settings_preview.ppm仅作预览。
- HDMI：真实SETTINGS_UI=1，三帧连续传输，沿用逐符号数据岛/音频解码断言；另验证菜单RGB十级延迟613120个像素及跨时钟状态字。

物理矩阵所有16个单键、120个双键和鬼键、真实顶层接线及四页控制上下限另由dmz_media和video_adjust/verify_control.py覆盖。

板级行为模型不替代上板检查。预览是RTL仿真输出，不是显示器实拍。
